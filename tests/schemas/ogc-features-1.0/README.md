# OGC API – Features schema snapshot

Unmodified response schemas from
<https://schemas.opengis.net/ogcapi/features/part1/1.0/openapi/schemas/>,
retrieved 2026-10-25. Relative references are included for offline validation;
`SHA256SUMS.json` records the downloaded bytes. These fixtures retain the OGC
schema licensing terms and are not application-owned schemas.

Used to validate the sample collection metadata, GeoJSON features and paged
FeatureCollections returned by the stock pygeoapi GeoJSON provider. This is
regression evidence, not certification of the service.
